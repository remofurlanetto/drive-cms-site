SeedPage

Websites without paid hosting: the content stays in your Google Drive or a Git repository.

Pages are Google Docs, configuration lives in Google Sheets, and the site is built into static HTML published on a static host such as GitHub Pages. Pages are edited in Google Docs or in SeedPage's author interface, which runs on the editor's own computer.

The application signs in with the editor's own Google account and reads and writes only the Drive files of the sites that person opens in it. Drive's own sharing decides what each person may see and change.
